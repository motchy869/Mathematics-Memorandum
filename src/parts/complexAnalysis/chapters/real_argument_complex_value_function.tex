\chapter{実引数複素数値関数}
    \section{負の周期の解釈}
        \noindent
        動機：Fourier 解析に於いては負の周波数成分を考えることになる。
        解析対象の関数が周期的であるとき，負の周波数成分に対応する周期を考える必要に迫られる。
        \par\noindent
        方針：周期の定義を拡張する。「1実数変数複素関数が，右回りに進行する向きを周期の符号とする」と定めれば，負の周期を定義できる。
        \par\noindent
        導かれること：1 変数実数値関数の周期は正のものに限られる
