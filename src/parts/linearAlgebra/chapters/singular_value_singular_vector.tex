\chapter{特異値，特異ベクトル}
    \section{極分解}
        \begin{shadebox}
            任意の複素正方行列はユニタリ行列と半正定値Hermite行列の積に分解できる。
        \end{shadebox}
        \begin{proof}
            $A\in\complexNumbers^{n\times n}$とし，特異値分解を$A=U\Sigma V^*$とする。
            $P=VU^*,B=PA$とすると$B=V\Sigma V^*$であり，$B$は半正定値Hermite行列である。
            そして$A=P^*B$と表せる。
        \end{proof}
